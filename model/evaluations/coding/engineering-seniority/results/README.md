# Results

This directory contains the result format, not preclaimed benchmark outcomes.

Do not invent scores for models that have not actually completed the evaluation. A published result should identify at least:

- model and version when verifiable;
- benchmark commit SHA;
- evaluation language;
- runtime and tool permissions;
- network policy;
- per-test scores;
- weighted score and Engineering Level;
- Exam Integrity status;
- enough evidence for another evaluator to audit the judgment.

For serious comparisons, run each model/configuration at least three times and report the individual runs, average, and variance.
